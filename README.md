# Neon Blok

Blokları 10x10 tahtaya yerleştir, dolan satır ve sütunları temizle.

**Oyna:** https://salihtombuloglu771-stack.github.io/neon-blok/

iPhone'da Safari'de aç → Paylaş → **Ana Ekrana Ekle**: uygulama gibi tam ekran açılır.

Bu depo yalnızca oyunun derlenmiş web sürümünü içerir (Unity WebGL).
